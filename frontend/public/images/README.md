# Folder Gambar / Foto Website

Letakkan foto secara manual di folder berikut, lalu pakai alamatnya (misal `/images/perangkat/lurah.jpg`)
di Panel Admin, atau cukup unggah langsung lewat tombol "Unggah" di Panel Admin.

| Folder      | Isi                                                   |
|-------------|-------------------------------------------------------|
| `kantor/`   | Foto kantor kelurahan (latar beranda & halaman login) |
| `logo/`     | Logo kelurahan / Kabupaten Banyumas                    |
| `perangkat/`| Foto perangkat kelurahan (rasio 4:5 disarankan)        |
| `sambutan/` | Foto Lurah untuk kotak sambutan                        |
| `berita/`   | Gambar sampul berita                                   |
| `galeri/`   | Foto kegiatan untuk galeri                             |
| `potensi/`  | Foto potensi & UMKM                                    |

Catatan: foto yang diunggah lewat Panel Admin otomatis dikompres dan disimpan di `backend/uploads/`.
